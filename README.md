# 🛡️ Fake Product Identification System

A full-stack web application that detects whether a product is genuine or fake using product details and QR code scanning.

---

## 🚀 Features

- Product verification using backend logic
- QR Code scanning using camera
- Instant result display (Genuine / Fake)
- Simple and clean UI
- Full-stack integration (HTML + Java + Spring Boot)

---

## 🛠️ Tech Stack

### Frontend:
- HTML
- CSS
- JavaScript
- html5-qrcode (QR Scanner library)

### Backend:
- Java
- Spring Boot
- REST API
